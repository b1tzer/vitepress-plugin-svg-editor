# 09 — 功能规划

> 功能按优先级分为 P0（MVP 必备）、P1（品质保障）、P2（差异化竞争力）、P3（未来愿景）。

---

## P0：核心编辑能力（缺一个就不叫编辑器）

| #   | 功能                 | 状态                                    | Fabric.js API                                                | 验收标准                                                |
| --- | -------------------- | --------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| F1  | **SVG 加载与渲染**   | 当前已有，需重构                        | `fabric.loadSVGFromString()` + `CanvasManager.init()`        | `.svg` 文件在 Canvas 中正确显示，CSS 变量已解析为颜色值 |
| F2  | **对象选中与拖拽**   | 当前已有（Fabric 内置）                 | `canvas.selection`, `canvas.getActiveObject()`               | 单击选中，显示控制框；拖拽移动位置                      |
| F3  | **缩放画布（滚轮）** | 当前已有                                | `canvas.zoomToPoint()`                                       | 滚轮缩放流畅，缩放级别 10%-500%                         |
| F4  | **撤销/重做**        | 当前已有                                | `HistoryManager`（自研）                                     | Ctrl+Z/Ctrl+Y，支持至少 50 步                           |
| F5  | **保存 SVG**         | 当前已有，需重构为 StorageAdapter       | `canvas.toSVG()` → `SvgSerializer` → `StorageAdapter.save()` | 编辑后保存，刷新页面 SVG 显示新内容                     |
| F6  | **文字编辑**         | 当前已有                                | `fabric.Textbox` 双击进入编辑                                | 双击文字进入编辑态，修改后确认                          |
| F7  | **箭头/连线**        | 当前已有（preprocessor marker→polygon） | `<marker>` 预处理 + `fabric.Group` 包裹线+箭头               | 箭头三角形正确显示，拖动时线与箭头同步移动              |

### P0 验收标准

```
[ ] 加载→编辑→保存 完整闭环通过 E2E 测试
[ ] undo/redo 50 步不崩溃、不丢数据
[ ] 编辑后的 SVG 文件在浏览器中正常显示（尺寸不为 0）
[ ] CSS 变量在编辑器中被正确解析为颜色值
[ ] 保存后的 SVG 文件不包含 Fabric.js 私有属性
```

## P1：品质保障（没有这些用户会觉得"不好用"）

| #   | 功能                      | 说明                                                  | Fabric.js API                                                                | 验收标准                                          |
| --- | ------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------- |
| F8  | **暗色/亮色主题切换**     | 编辑器内实时预览明暗配色（语义 token + OKLCH 自适应兜底） | `useTheme` 三级策略：语义色优先 → hex 精确映射 → 双向记忆化 + OKLCH 翻转 | dev 模式下切换主题按钮，编辑器内 SVG 颜色跟随变化（含自定义色） |
| F9  | **文字格式工具栏**        | 字号、加粗、斜体、下划线、颜色、对齐                  | `textbox.setFontSize()`, `setBold()`, `setFill()`, `setTextAlign()`          | Ctrl+B/I/U 快捷键生效                             |
| F10 | **层级控制**              | 上移一层/下移一层/置顶/置底                           | `canvas.bringForward()`, `sendBackwards()`, `bringToFront()`, `sendToBack()` | 4 个层级按钮生效                                  |
| F11 | **对齐**                  | 左对齐/水平居中/右对齐/顶部对齐/垂直居中/底部对齐     | 基于选中对象 bounds 计算偏移                                                 | 选中 2+ 个对象对齐正确                            |
| F12 | **等间距分布**            | 水平等距/垂直等距                                     | 基于选中对象 bounds 计算间距                                                 | 选中 3+ 个对象等距排列                            |
| F13 | **边框粗细和样式**        | 0.5px-5px 粗细 + 实线/虚线                            | `object.set('strokeWidth', n)`, `set('strokeDashArray', [n, n])`             | 边框属性即时生效                                  |
| F14 | **快捷键完整覆盖**        | Ctrl+S 保存, Ctrl+Z/Y 撤销, Esc 关闭, Delete 删除选中 | 全局 keydown 监听                                                            | 所有核心操作有快捷键                              |
| F15 | **SVG 预处理/后处理钩子** | 加载时清洗、保存时还原                                | 用户自定义 `preprocess`/`postprocess` 函数                                   | 自定义钩子被调用且不破坏 SVG 结构                 |
| F16 | **保存确认 & 错误提示**   | Toast 提示"保存成功/失败"，失败时保留编辑内容不丢失   | `StorageAdapter.save()` 返回值判断                                           | 保存失败时编辑器不关闭，内容不丢失                |

### P1 验收标准

```
[ ] 工具栏所有按钮（≥10 个）可点击且有视觉反馈
[ ] 暗色/亮色模式切换：编辑器内 SVG 颜色从亮色变量变为暗色变量
[ ] 所有快捷键在 Chrome + Firefox 上生效
[ ] preprocess/postprocess 钩子在测试用例中被调用
```

## P2：差异化竞争力（让你和竞品拉开差距的功能）

| #   | 功能                      | 说明                                      |
| --- | ------------------------- | ----------------------------------------- |
| F17 | **辅助线（Guide Lines）** | 拖拽时自动显示对齐辅助线（Snap to align） |
| F18 | **标尺（Ruler）**         | 画布顶部和左侧的像素标尺                  |
| F19 | **缩放至实际尺寸**        | 一键 100% 缩放                            |
| F20 | **导出 PNG**              | 将 SVG 渲染为 PNG 下载                    |
| F21 | **渐变编辑器**            | 可视化编辑 linearGradient/radialGradient  |
| F22 | **阴影编辑器**            | 可视化编辑 drop-shadow                    |
| F23 | **对象锁定**              | 锁定对象防止误操作                        |
| F24 | **复制/粘贴/剪切**        | Ctrl+C/V/X，支持跨分页                    |
| F25 | **栅格 Grid**             | 显示/隐藏背景网格，吸附到网格点           |

## 功能依赖图

```
P0 ──────────────────────────────────────────────
  │
  ├── F1(SVG加载) ──┬── F2(选中拖拽) ── F3(缩放)
  │                 ├── F5(保存) ────── F4(undo)
  │                 ├── F6(文字编辑)
  │                 └── F7(箭头)
  │
P1 ──────────────────────────────────────────────
  │
  ├── F8(主题) ←── 依赖 useTheme composable + colors 常量
  ├── F9(文字格式) ←── 依赖 F6
  ├── F10(层级) ←── 依赖 F2
  ├── F11(对齐) ←── 依赖 F2
  ├── F12(等距) ←── 依赖 F2
  ├── F13(边框) ←── 依赖 F2
  ├── F14(快捷键) ←── 依赖 F4/F5/F10
  ├── F15(处理钩子) ←── 依赖 F1/F5
  └── F16(保存确认) ←── 依赖 F5

P2 ──────────────────────────────────────────────
  │
  ├── F17(辅助线) ←── 依赖 F2
  ├── F18(标尺) ←── 独立
  ├── F19(实际尺寸) ←── 依赖 F3
  ├── F20(导出PNG) ←── 独立
  ├── F21(渐变) ←── 独立
  ├── F22(阴影) ←── 独立
  ├── F23(锁定) ←── 依赖 F2
  ├── F24(复制粘贴) ←── 依赖 F2
  └── F25(栅格) ←── 独立
```
